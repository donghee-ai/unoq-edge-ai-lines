# History — 의사결정/진행/마일스톤 실시간 기록

본 작품 진행 중 **의사결정 / 마일스톤 / 자산 추가 / 환경 변경 / 측정 완료 / 멘토 피드백** 등 일반 진행 사항을 실시간 기록.

## 파일명 규칙

```
<YYYY-MM-DD>_<NN>_<짧은_제목>.md
```

- `NN` = 그날의 일련번호 (01, 02, ...)
- 짧은_제목 = 영문 lowercase + underscore (예: `model_decision`, `vision_demo_done`)
- 예: `2026-06-25_01_workflow_established.md`

## 작성 형식 (각 사건 1 파일)

```markdown
# <한 줄 제목>

## 시점
YYYY-MM-DD HH:MM (선택)

## 사건
무엇이 일어났는가 (사실 위주)

## 배경
왜 진행했는가 (있으면)

## 결과
- 산출물 / 결정 / 측정값
- 다음 단계

## 관련
- 관련 issues / history / docs 파일 링크 (선택)
```

## 기록 시점

**일이 생기는 즉시**:
- 의사결정 (모델 선택, 라이브러리 결정, 합격선 변경 등)
- 자산 추가/삭제 (모델 다운로드, 파일 생성/삭제)
- 환경 변경 (Docker rebuild, 의존성 추가, 디바이스 패키지 설치)
- 측정 완료 시 핵심 수치
- 멘토 보고 / 멘토 피드백 받음
- 작업 시작 / 종료 / 재시작 시점
- 새 워크플로우 / 규칙 채택

## `issues/`와의 구분

| 폴더 | 내용 |
|---|---|
| `issues/` | **문제** / 오류 / 함정 → 진단 / 해결 / 재발 방지 |
| `history/` | **정상 진행** / 의사결정 / 마일스톤 / 결과 |

같은 사건이 둘 다 해당하면 양쪽에 (서로 링크).
