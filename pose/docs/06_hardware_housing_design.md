# 하드웨어 하우징 디자인 (Pose 라인)

본 문서는 본 작품 하드웨어 외형/하우징의 디자인 컨셉 + 색상 + 결정 옵션 정리. 2026-06-27 멘토 미팅 결정 기반.

> **현 단계 위치**: 본 작품 하우징은 PTZ 검증 PoC([`08_ptz_camera_angle_validation.md`](08_ptz_camera_angle_validation.md))와 함께 진행. **PoC 통과 후 정식 통합** 결정. PoC 실패 시 하우징은 카메라 고정 형태로 단순화 가능.

## 0. 결정 컨셉

| 항목 | 결정 |
|---|---|
| **모티프** | 두 옵션 중 택일 — (A) 귀여운 캐릭터 형태 OR (B) Qualcomm 드래곤 컨셉 (드래곤윙 프로세서 참조) |
| **색상 베이스** | **파란색 + 흰색** (양 옵션 공통, Qualcomm 브랜드 색 일관성) |
| **본체 이동 여부** | 정지 (PTZ로 카메라만 회전, 자율 주행 X) |

## 1. 옵션 A — 귀여운 캐릭터 형태

### 1-1. 컨셉
- 친근감/접근성 강조
- 헬스케어 봇 사용처 (사용자가 매일 보는 운동 코치)에 자연스러움
- 작은 동물/마스코트 모티프 (강아지/곰/펭귄 등 검토)

### 1-2. 디자인 요소
- 둥근 형태 (날카로운 모서리 최소화 — 안전 + 친근)
- 카메라 = 눈 모티프 (1개 또는 2개)
- LED 표정 (rep 카운트 / 음성 응답 시 깜빡임)
- 본체 크기 ~15-20 cm 정도 (책상에 둘 만한 크기)

### 1-3. 색상 배분 (파랑 + 흰색)
- 본체 메인 = 흰색 (밝고 깨끗)
- 포인트/액센트 = 파란색 (눈/이마/마크 등)
- 비율 70% 흰색 + 30% 파란색 권장

## 2. 옵션 B — Qualcomm 드래곤 모티프

### 2-1. 컨셉
- Qualcomm 드래곤윙 프로세서 (QRB2210) 이름 참조
- 브랜드 정체성 강조 — 멘토/Qualcomm 보고 사이클에 친화적
- 다소 유니크한 외형 — 시연/전시 시 주목성 ↑

### 2-2. 디자인 요소
- 드래곤 머리/날개 모티프 (간략화)
- 카메라 = 드래곤 눈 (1개, 중앙)
- LED = 비늘/입김 효과
- 본체 크기 ~20-25 cm (드래곤 형태로 적당 비율)

### 2-3. 색상 배분
- 본체 메인 = 흰색 (드래곤 비늘)
- 날개/이빨/포인트 = 파란색 (드래곤윙 강조)
- 비율 60% 흰색 + 40% 파란색

## 3. 양 옵션 공통 요구사항

### 3-1. 내부 구조 수용
- UNO Q 디바이스 (QRB2210 보드, 약 ~10 × ~7 cm)
- USB UVC 카메라 (SU200, 작음 — PTZ 서보 마운트 위에 부착)
- USB UVC 마이크 (ASR 라인 — 본체 안 또는 상단)
- STM32U585 보드 (서보 PWM 제어)
- 서보 2개 (pan/tilt)
- LED 1~2개 (rep 카운트 / 음성 응답 / 표정)
- USB 케이블 외부 연결 포트
- 통풍 — UNO Q thermal 71°C 도달, 통풍 필수 (개구부 또는 작은 팬)

### 3-2. PTZ 카메라 마운트
- 본체 상단에 회전 마운트
- pan(좌우) ±60° 정도 (Shawn 프로젝트 HORIZONTAL_FOV 60° 기반)
- tilt(상하) ±30° 정도
- 마운트 자체는 본체 내 + 카메라만 외부 노출
- **출처**: ShawnHymel/face-expression-detection-robot `mechanical/` STL 7개 (MIT) — PoC 단계 활용

### 3-3. 케이블 관리
- USB-C 1개 (UNO Q 전원/통신)
- 추가 케이블 최소 (마이크/카메라는 USB 허브 통합)
- 외부 케이블 정리 — 깔끔한 시각

## 4. 제작 방법 후보

| 방법 | 장단점 |
|---|---|
| 3D 프린팅 (PLA) | 빠른 시제품, 자유 형상, 저비용. 마감 거침 |
| 3D 프린팅 + 도색 | 마감 매끄러움 ↑, 추가 시간 |
| 아크릴/MDF 조립 | 깔끔한 면, 곡선 어려움 |
| 시판 케이스 + 커스텀 외피 | 빠름. 디자인 제한 |

본 작품 마감 일정 + 시연 품질 고려해 **3D 프린팅 + 도색** 또는 **시판 케이스 + 외피 스티커** 권장.

## 5. 결정 보류 항목

| 항목 | 결정 시점 |
|---|---|
| A vs B 옵션 선택 | 디자인 시제품 1~2회 후 |
| 정확한 치수 | 내부 부품 배치 확정 후 |
| 제작 방법 | 일정 + 비용 평가 후 |
| 도색 색상 코드 (파란색 hex / 흰색 명도) | 시제품 단계 |

## 6. 영향

- 본 라인 코드 / 알고리즘 변경 없음 — 하우징은 외형만
- 카메라 위치 변동 가능 (지면 10 cm → 무릎 높이 등) — 본체 형태 따라
- 카메라 PTZ 마운트 — STM32 펌웨어 + 서보 통합 작업과 동기 진행
