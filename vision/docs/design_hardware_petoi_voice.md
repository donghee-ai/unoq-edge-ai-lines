# Concept — 로봇 강아지 + 음성 명령(ASR)

## 한 줄 컨셉

> **오픈소스 사족 로봇(Petoi Bittle)을 본체로 삼고, UNO Q를 얹어 음성으로 명령을 내리면 강아지처럼 반응하는 교감로봇을 만든다.**

## 구성

| 요소 | 역할 |
|---|---|
| **Petoi Bittle** (오픈소스 사족 로봇) | 본체 — 보행, 자세, 동작 |
| **Arduino UNO Q** | 두뇌 — 음성 인식(ASR) + 명령 변환 |
| **USB 마이크** | 음성 입력 |
| **3D 프린팅 외장 (Petoi STL + 백팩 마운트)** | UNO Q를 Bittle 위에 고정 |

## 동작 흐름

```
사람이 말함 ─▶ 마이크 ─▶ UNO Q (ASR) ─▶ 명령 변환
                                          │
                                          ▼
                                   Bittle 동작 수행
                                   (앉기 / 걷기 / 인사 …)
```

## 명령 예시

| 발화 | 동작 |
|---|---|
| "앉아" | 앉기 |
| "이리 와" | 앞으로 걷기 |
| "안녕" | 인사 |
| "멈춰" | 정지 |
